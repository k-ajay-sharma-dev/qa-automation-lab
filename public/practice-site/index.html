ShopEasy automation playground

A small fake web shop built for practising Selenium WebDriver, Cucumber and the Page Object Model. Everything runs in your browser — no backend, no real orders. Base URL: http://localhost:5180/practice-site/

Login
  • Locators by id / name / data-testid
  • Positive + negative login (locked-out user, empty fields)
  • Reading the error banner text
Inventory
  • Lists of elements (findElements)
  • Sort dropdown with the Select class
  • Add/Remove toggle and cart badge count
Cart
  • Verifying line items added on another page
  • Removing items, empty-cart state
Checkout
  • Form validation messages
  • Totals maths: item total + 8% tax
  • End-to-end Cucumber scenario: login → buy → confirm
Registration form
  • Radio buttons, checkboxes, single and multi-select
  • Date input, textarea, file upload with sendKeys(path)
  • Data-driven tests (Scenario Outline / DataProvider)
Web table
  • Reading rows and cells, column sort checks
  • Search filter and pagination (5 per page)
  • "Click Edit in the row where Name = X"
Waits
  • Explicit waits / ExpectedConditions
  • Spinners, delayed enable, changing text
  • StaleElementReferenceException, "Load more"
Alerts
  • JS alert / confirm / prompt via switchTo().alert()
  • Waiting for a delayed alert
  • HTML modal dialogs (no switching needed)
Frames
  • switchTo().frame() by id, name, WebElement
  • Nested iframe, parentFrame() / defaultContent()
Windows
  • New tab via target=_blank and pop-ups
  • getWindowHandles() and switching back
Dynamic / tricky
  • Generated ids, duplicate classes, text-only buttons
  • Shadow DOM, hover menus, drag and drop
  • XPath axes: pick by sibling text
