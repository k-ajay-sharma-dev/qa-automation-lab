Tricky locators

This page is built the way real front-end frameworks build pages: generated ids, reused class names, components with no test hooks. Reload the page and watch the ids change (inspect with DevTools).

Last action: none

1. Auto-generated ids

The framework appends a random hash to every id on each page load, e.g. btn-8f3a2. Only the prefix is stable.

2. Pricing plans (same classes everywhere)

Every card is a div.plan and every button is .btn.btn-primary. One card is highlighted.

3. Buttons that differ only by text

Product description editor. No ids, same classes — only the visible text tells them apart.

6. Shadow DOM widget

The coupon box is a web component. Its input and button live inside an open shadow root — normal CSS/XPath from the document cannot see them. Use driver.findElement(By.cssSelector("coupon-widget")).getShadowRoot() (Selenium 4).

7. Hover menu

The submenu only appears while the mouse is over "My account". Use new Actions(driver).moveToElement(...).
